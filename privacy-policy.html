Política de Privacidade

Esta Política de Privacidade descreve como o aplicativo CalenCar coleta, utiliza e protege as informações dos usuários.

O aplicativo foi desenvolvido para auxiliar no controle de manutenção e informações de veículos.

1. Coleta de dados

O aplicativo pode armazenar informações inseridas diretamente pelo usuário, como:

  • Dados dos veículos cadastrados
  • Histórico de manutenção
  • Quilometragem
  • Lembretes e registros relacionados ao veículo

O aplicativo não coleta dados pessoais sensíveis sem o consentimento do usuário.

2. Uso das informações

As informações armazenadas são utilizadas exclusivamente para fornecer as funcionalidades do aplicativo, incluindo:

  • Controle de manutenção do veículo
  • Registro de histórico
  • Lembretes e alertas
  • Organização de informações relacionadas ao veículo

3. Armazenamento de dados

Os dados são armazenados localmente no dispositivo do usuário.

Opcionalmente, o usuário pode ativar o backup em nuvem para proteger suas informações.

4. Backup em nuvem

Quando autorizado pelo usuário, o aplicativo pode salvar backups no Google Drive utilizando a conta Google conectada ao dispositivo.

O acesso ao Google Drive é utilizado exclusivamente para armazenar e restaurar backups dos dados do aplicativo.

O usuário pode desativar essa funcionalidade a qualquer momento nas configurações do aplicativo.

5. Serviços de terceiros

O aplicativo utiliza serviços fornecidos por terceiros para algumas funcionalidades:

  • Google Drive: utilizado para armazenar backups dos dados do aplicativo.
  • Conta Google: utilizada para permitir a sincronização e recuperação de backups.

Esses serviços podem coletar e processar dados de acordo com suas próprias políticas de privacidade.

6. Uso da internet

O aplicativo utiliza conexão com a internet para consultar APIs externas que fornecem informações de marcas e modelos de veículos.

Esses dados são utilizados apenas para facilitar o preenchimento automático durante o cadastro de veículos.

Nenhuma informação pessoal do usuário é enviada nessas consultas.

7. Compartilhamento de dados

O aplicativo não vende, aluga ou compartilha informações pessoais dos usuários com terceiros.

8. Permissões do aplicativo

O aplicativo pode solicitar permissões necessárias para seu funcionamento, como:

  • Acesso à internet
  • Acesso à conta Google para backup em nuvem
  • Acesso ao armazenamento para salvar backups

9. Controle do usuário

O usuário pode excluir seus dados a qualquer momento removendo as informações dentro do aplicativo ou desinstalando o aplicativo do dispositivo.

10. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir melhorias ou alterações no aplicativo.
